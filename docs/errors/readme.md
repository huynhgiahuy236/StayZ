# Nhật Ký Lỗi & Phân Tích Lỗi Hệ Thống (System Error Logs)

Thư mục này dùng để tự động ghi nhật ký các lỗi phát sinh trong quá trình chạy ứng dụng, kiểm thử API, kết nối CSDL hoặc build source code.

## Quy tắc ghi log:
- Mỗi khi phát hiện lỗi trong quá trình thực thi hoặc nhận lệnh `fix`, AI sẽ ghi log lỗi dạng `error-YYYY-MM-DD.log` hoặc `error-XXXX.md` trong thư mục này.
